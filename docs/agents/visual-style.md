# Personal Blog Visual Style

This document defines the visual language for the personal blog. It constrains visual presentation only; it does not prescribe content structure, page modules, feature priority, or product behavior.

## Style direction

- **Core character:** calm and professional, with a refined minimalist finish.
- **References:** [innei.in](https://innei.in/) and the Yohaku (余白) design system.
- **Design philosophy:** center writing and reading rather than presentation or marketing. A page should feel like a sheet of correspondence unfolding at an unhurried pace, with typography and whitespace creating the rhythm together.
- **Keywords:** calm, professional, clean, restrained, breathable, refined, paper-like, comfortable for nighttime reading.
- **Avoid:** playful or busy treatments, decorative excess, marketing aesthetics, strong visual impact, and heavy-handed technology aesthetics such as neon, glassmorphism, or abundant motion.

## Design principles

1. **Whitespace first.** Use generous, intentional empty space and keep information density low. Prefer space over crowding.
2. **Use color sparingly.** Use neutral colors plus exactly one soft accent color per color scheme.
3. **Let typography establish hierarchy.** Prefer type size and weight over color and decoration for differentiation.
4. **Put reading comfort first.** Every visual decision should support comfortable long-form reading.

## Color palette

### Light mode (default)

| Role | Value | Usage |
| --- | --- | --- |
| Page background | `#FEFEFB` | Warm, paper-like off-white |
| Secondary surface / card | `#F7F6F2` | Subtle surface separation |
| Primary text | `#1A1A1A` | Near-black for clear reading |
| Secondary text | `#6B6B6B` | Dates, tags, and supporting information |
| Border / divider | `#E5E4DF` | Very light warm gray |
| Accent | `#33A6B8` | Soft asagi blue for links, focus, and small details |

### Dark mode

| Role | Value | Usage |
| --- | --- | --- |
| Page background | `#1C1C1E` | Warm dark gray rather than pure black |
| Secondary surface | `#2C2C2E` | Slight visual elevation |
| Primary text | `#EDEDED` | Soft near-white |
| Secondary text | `#A1A1A6` | Supporting information |
| Border / divider | `#3A3A3C` | Low-contrast boundary |
| Accent | `#F596AA` | Soft peach-pink counterpart to the light theme |

### Color rules

- Use the accent only for links, hover states, focus rings, a small number of icons, or quote markers.
- Never use the accent across large areas.
- Do not introduce additional high-saturation or high-contrast colors.
- Use the neutral palette above for backgrounds, surfaces, text, borders, and dividers.

## Typography

- Prefer modern sans-serif typefaces with a clear, calm character.
- Establish hierarchy with font size and weight, not decorative color changes.
- Use comfortable line height and optimize for extended reading.
- Support mixed Chinese and Latin text without disrupting rhythm or legibility.
- Do not use decorative serif or handwritten typefaces for body copy.

## Density and spacing

- Keep the overall composition loose and spacious.
- Use generous spacing between elements so the page can breathe.
- Avoid stacked cards, dense grids, and strong or frequent dividers.
- Do not fill empty areas merely to increase visual activity.

## Motion and effects

- Keep motion subtle, infrequent, and functional.
- Avoid showy animation, glassmorphism, neon effects, and effects that compete with reading.
- Do not rely on motion or visual novelty to communicate basic hierarchy.

## Non-goals

This guide does not determine:

- content hierarchy or information architecture;
- which sections, modules, or components a page must contain;
- feature scope or implementation priority;
- interaction behavior beyond the visual restraint described above.

When those decisions are not specified elsewhere, preserve the existing product structure rather than inferring it from this visual guide.
